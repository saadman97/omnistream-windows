# OmniStream for Windows

This repository contains the standalone, portable Windows executable for **OmniStream**, a cross-platform media directory browser and native FTP video streaming player.

## Features
- **Standalone Portable Executable**: No installation required. Just download and run.
- **Native FTP Video Streaming**: Built-in FTP proxy that routes streams locally for seamless browser-level playback.
- **Modern Video Engine**: Powered by Plyr for a premium, VLC-like web player experience.
- **HLS/DASH Support**: Full support for standard formats alongside HLS and DASH streams.
- **Keyboard Shortcuts**: Fully mapped VLC shortcuts (Space, Arrows, J/L, M, F).
- **Clean UI**: Modern file manager layout for browsing HTTP/FTP directories.
