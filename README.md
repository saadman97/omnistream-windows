## 🚀 Overview

**OmniStream** is a powerful, cross-platform **Media Directory Browser** and **Native FTP Video Streaming Player** designed to bridge the gap between traditional file managers and modern web video playback. 

With OmniStream, you can effortlessly browse HTTP and FTP directories and stream videos directly without downloading them. This repository hosts the **Standalone Portable Windows Executable (`.exe`)**—requiring absolutely no installation. Just download and run!

## ⚡ Key Features

* **Native FTP Video Streaming**: Unlike standard browsers that block FTP, OmniStream uses a built-in proxy to route FTP streams locally, allowing for instant, buffer-free playback directly from your FTP servers.
* **Premium VLC-Like Web Player**: Powered by **Plyr**, OmniStream offers a state-of-the-art HTML5 video engine that feels just like a premium desktop media player (VLC alternative).
* **HLS & DASH Streaming Support**: Native integration with `hls.js` and `dash.js` ensures seamless streaming across all modern video formats and HTTP Live Streaming protocols.
* **HTTP 206 Range Seeking**: Supports partial content requests, meaning you can instantly seek to any part of a massive video file without waiting for it to buffer.
* **Advanced Keyboard Shortcuts**: Fully mapped for power users with standard VLC shortcuts:
  * <kbd>Space</kbd> / <kbd>K</kbd>: Play & Pause
  * <kbd>←</kbd> / <kbd>→</kbd>: Seek backward / forward 10s
  * <kbd>J</kbd> / <kbd>L</kbd>: Fast seek backward / forward 30s
  * <kbd>↑</kbd> / <kbd>↓</kbd>: Volume control
  * <kbd>M</kbd>: Mute
  * <kbd>F</kbd>: Fullscreen
* **Modern File Manager UI**: Navigate through your media with a clean, tabular layout (Name, Type, Size, Modified Date) inspired by the best FTP clients and file managers.
